## Important: add your real portfolio projects
The three Work cards are designed placeholders, not representations of verified client projects. They currently link to your Behance profile. Replace the visual placeholders with your own project images and update the project titles/descriptions.

To add a project image:
1. Create an `images` folder in the repository.
2. Upload your project image, for example `brand-project.jpg`.
3. In `index.html`, replace the corresponding `.project-visual` placeholder with an image element, or use the image as a CSS background.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for deployment and open the URL shown in the Pages settings.

No build tools or frameworks are required.
